# T11 接入 Agent 诊断

依赖 T02、T03、T05、T07、T08，前置任务已完成；本任务以 T10 提交 290004d 为基础。仅推进诊断后端，不实现 T12/T13 页面或 T15 线上评测。

## 实现内容

- 新增 TaskDiagnosis、TaskEvidenceTools、DiagnosisPolicy，使用既有 Spring AI 单轮网关，由应用显式执行只读工具。默认真实 HTTP 查询独立模拟服务，模型为无费用工程替身；可配置既有 deepseek 网关。
- 查询范围绑定服务端任务订单，支付 ID 只能从该订单证据提取。历史工具读取本应用该订单执行历史。拒绝越权、未知工具、额外参数及无效 JSON。
- 支持 NO_ACTION、WAIT、MANUAL、RECOMMEND_RECHECK；建议修复必须通过引用、金额、关联、支付/回调状态和历史规则校验。冻结参数完全从服务端证据生成，不信任模型参数，不自动审批或执行。
- V7 新增 diagnosis_run、不可变 diagnosis_event，扩展方案来源 AGENT_VALIDATED。保存调用前意图、轮数/工具预算、每轮公开输出、用量/耗时、证据引用和最终结论。工具事实保存在既有 evidence 中。
- 模型与 HTTP 调用均在事务外。每次提交锁任务并验证 epoch/版本/租约；取消/接管使旧 Worker 无法写入。预算在调用前持久化，重启不重置；恢复基于已有证据重新调用模型。
- WAIT 持久化复查批次及 next_run_at，释放线程/租约；重新获取证据但不重置累计预算。达到复查或总预算上限转人工并保留限制。
- 新增有角色及订单范围保护的 `GET /api/tasks/{id}/diagnosis` 和 VIEW_DIAGNOSIS。配置与 Compose 已同步，默认启用新诊断；旧固定方案实验通过显式 legacy-test 继续回归。

使用说明：[诊断 API](../api/diagnosis.md)。关键取舍：[决策 011](../decisions/011-t11-persistent-diagnosis.md)。

## 边界

没有运行新的真实付费模型调用，不能将替身通过称为真实模型效果。Spring AI 网关的原有本地协议测试随完整回归执行；T02 线上兼容实验属于历史证据，不代替 T11 在线评测。费用估算当前不可用，未获得的用量不按零计；恢复可能重复产生费用。

进程退出测试在四份证据落库后终止真实容器；若租约尚未释放，测试显式使租约到期，不等待默认 30 秒自然到期。不覆盖任意机器断电位置或每个网络窗口。模型意图未完成的恢复位置由专用数据库测试构造，已与真实 KILL 场景区分。

所有订单仍是模拟数据。历史工具只覆盖本应用执行记录，不证明系统外没有操作。公开解释采用规则说明，原模型公开输出保留以便核对；不保存隐藏推理。预算、引用校验不构成对提示词注入的普遍证明。

无前端变更，未部署、推送或迁移既有演示数据。升级会改变既有 QUEUED/DIAGNOSING 的默认处理方式；已冻结方案保持原样。
