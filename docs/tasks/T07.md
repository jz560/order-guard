- `WorkerLeaseIT`：真实 PostgreSQL 并发/锁/过期/版本/原子回滚验证。`TaskWorkerTest`：步骤失败与数据库写回失败分流、配置及非演示环境边界。
- `T07WorkerIT`：独立 JVM 双 Worker、创建后自动推进及新进程续跑；复用 T06 的隔离服务夹具。
- FoundationIT 迁移数期望更新为 3。T06 测试显式关闭 Worker，保留原创建事务断言；不是跳过并发验证。
- README、任务 API、`.env.example` 与 Compose 更新配置和运行边界。没有新增 Maven/npm 依赖。

| 验收项 | 验证方式 |
| --- | --- |
| 双 Worker 竞争 | 真实 PostgreSQL 同时认领同一任务只有一方成功；独立 JVM 双 Worker 推进多个任务，每任务只有两条成功步骤 |
| 锁与吞吐边界 | JDBC 显式锁定首个任务，另一个认领通过 SKIP LOCKED 取得后续任务 |
| 旧 Worker 隔离 | 真实数据库中过期租约、旧 epoch（即使 owner 相同）、错误 owner、旧版本及状态变化均拒绝写回，没有步骤副作用 |
| 等待释放 | next_run_at 未到期不认领；等待审批时 lease_owner/lease_until/next_run_at 为空，新任务仍继续推进 |
| 有限失败重试 | 持久化失败次数与未来运行时间，达到测试上限转 MANUAL/TEST_STEP_FAILED，订单限制仍存在 |
| 原子提交 | 数据库约束故意拒绝步骤记录，状态、租约释放及推进审计一起回滚；原有效认领可在解除故障后提交 |
| 状态边界 | APPROVED、EXECUTING、UNKNOWN、等待及终态均不被测试 Worker 认领；跳过审批直接进入 EXECUTING 的转换被拒绝 |
| 独立进程续跑 | 第一进程完成 TEST_START 后关闭，新进程使用已保存的下一步时间完成 TEST_WAIT，TEST_START 不重复 |
| API 权限 | 步骤查询支持游标；未认证拒绝、越权任务 404、分页非法 400；步骤文本明确标注无真实方案 |
| 异常分流 | 单元测试区分步骤异常与数据库写回异常，后者不误记步骤失败或提前释放租约；生产/混合 profile 不认领 |

租约过期案例通过专用测试数据库设置过期时间，以验证真实 SQL 条件与事务行为；不是实际挂起旧 Java 进程后恢复的 SIGKILL 实验。跨服务实验则运行真实独立 Java 容器。两者验证范围分开报告。

## 运行与限制

- `WORKER_ENABLED=true` 默认仅在纯 demo/test 生效；false 可保留 T06 的静态任务创建行为。
- 默认扫描间隔 500ms、租约 30000ms、两步间隔 1000ms、失败重试间隔 1000ms、连续失败上限 3。设置项及取值范围见 [任务 API](../api/tasks.md)。
- 不依赖页面连接，等待下一次执行和审批时清除 owner/lease；等待审批还清空 next_run_at。订单限制始终保留。
- 当前测试步骤没有模型/远程调用，也没有续租线程。旧执行者超出租约后不能提交结果，下一认领继续当前持久化状态。不能将此演示 Worker 描述为已实现完整生产诊断执行器。
- 步骤失败达到上限转人工并保留限制；数据库写回失败依赖租约过期恢复。长期数据库不可用时只记录错误并在后续扫描重试，不报告成功。
- 未部署常驻 Compose 服务，未新增前端交互；实际 SIGKILL 崩溃窗口验证仍是 T04/T14 范围，T07 独立进程重启测试不冒充 SIGKILL。
