# T01：建立可启动工程

范围：后端与模拟服务基础、前端基础、独立数据库和账号、迁移、健康检查、模型接口及默认替身、固定依赖和运行文档。

不在本任务实现订单诊断、审批、修复接口、Worker、业务场景或真实模型调用。

## 产物

- 根 Maven 工程及官方 Wrapper；Java 21；Spotless 和格式化器固定版本。
- backend、simulator 两个 Spring Boot 服务，独立 Flyway 入口与 V1 服务归属标记。
- `infra/postgres/init-databases.sh`：独立角色、数据库和权限限制。
- `compose.yaml`、Dockerfile、健康探针、`.env.example`、`.gitignore`。
- `ModelGateway` 和默认 `StubModelGateway`，无供应商凭证也可启动。
- Vue 3 + TypeScript + Vite，健康状态页，lint、类型检查、单次测试和构建命令。
- 模型边界单元测试、真实 PostgreSQL 的启动/隔离/迁移集成测试、前端状态与刷新测试。

### 验收证据对应

- **无模型密钥启动**：Compose 不传任何模型密钥，backend 正常健康；集成测试同时确认注入的是 StubModelGateway。
- **两服务独立数据库**：各集成测试断言 current_database、current_user 及服务归属标记。
- **账号隔离**：两个集成测试分别使用自身账号连接对方数据库，均收到 PostgreSQL SQLState 42501，未使用协议模拟。
- **空库迁移与再次启动**：每个集成测试创建临时真实 PostgreSQL，复用交付初始化脚本，两次启动 Spring 应用。成功迁移始终只有一条，归属记录初始化时间不变。
- **健康检查与访问边界**：实际 HTTP 检查 UP；未授权访问其他管理路径返回 403，健康响应不含详细组件或密码。
- **模型替身边界**：诱导修复的输入仍返回带 stub 标记、空证据的 MANUAL 结果；未知模型模式被拒绝。
- **前端基础**：验证健康/非健康/非法响应/网络异常、检查期间按钮禁用和刷新后的状态变化。
