## 范围与依赖

## 实现

- 新增 `backend/.../approval/`：PlanRecords、PlanMapper、PlanService、PlanController。
- Worker 完成测试诊断时，从持久化订单快照生成 version=1、source=TEST_STUB 的固定方案，冻结动作、订单、支付号、整数金额、币种、预期业务版本；SHA-256 绑定规范参数；有效期 15 分钟。方案、等待状态、步骤和审计同事务写入。
- 新增 `GET /api/tasks/{id}/plan`、`GET /api/plans/{id}`、`POST /api/plans/{id}/decision`。提供参数、版本、有效期、来源、证据 ID、服务端时间、审批记录和允许操作。
- 批准只允许权限范围内的审批员；审批身份来自会话；写请求保留 CSRF 防护；请求不接受自行提交的身份或参数。批准、拒绝的任务状态、唯一决定和审计原子落库。
- 完全相同的决定重放不重复更新状态、审计或有效期；改决定/原因、旧版本、错误摘要、非最新方案被拦截。数据库触发器禁止修改/删除方案和最终审批。
- 拒绝终止为 FINISHED/PLAN_REJECTED；未开始执行的等待/批准方案过期后终止为 FINISHED/PLAN_EXPIRED，并释放订单限制。已批准但未到期仍保留限制。过期后的原决定重放只读取历史，不恢复授权。
- Flyway 新增 `V4__frozen_plans_and_approvals.sql`，旧迁移不修改。升级时将 T07 无方案 WAITING_APPROVAL 测试任务恢复到 DIAGNOSING，保留历史步骤，启用 Worker 后补建方案。
- 更新安全路径、任务 VIEW_PLAN 操作、Worker、迁移计数和 T07 固定步骤断言；增加 7 项审批数据库测试、4 项独立服务 HTTP 测试以及 1 项方案/等待状态原子性与旧 Worker 测试。无新增依赖或配置变量。

设计选择见 [决策 008](../decisions/008-t08-frozen-plan-approval.md)，接口和 PowerShell 体验步骤见 [方案审批](../api/plans.md)。
